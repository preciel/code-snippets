# Symfony snippets

Files here mirror the Symfony project directory structure. Each file can be dropped into the matching path of a Symfony project.

## Contents

| File | Description |
|------|-------------|
| `assets/scripts/symfony-toolbar-extension.js` | Injects a screen/viewport dimensions block into the Symfony web debug toolbar |
| `config/packages/doctrine.yaml` | Doctrine configuration |
| `src/Doctrine/DBAL/Types/TinyintType.php` | Custom Doctrine DBAL type for `TINYINT` columns |
| `src/Extension/PhpExtension.php` | PHP utility extension |
| `src/Extension/TwigExtension.php` | Twig utility extension |
