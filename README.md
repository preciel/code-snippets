# code-snippets

A personal collection of reusable code snippets — utilities, helpers, and patterns worth keeping around.

Most of the code here originates from old personal projects, salvaged and refactored up to modern standards before being archived here.

## Structure

```
javascript/     JS snippets, one subfolder per snippet
php/            PHP snippets, one subfolder per snippet
  symfony/      Symfony-specific snippets
```

Each snippet lives in its own subfolder with a `README.md` covering its purpose and usage.
